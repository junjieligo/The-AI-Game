# Self-hosted typefaces

Nunito (English and pinyin) and Noto Sans SC (simplified Chinese). SIL Open Font License texts are included. No Duolingo proprietary font is bundled. Chinese is subset to the game text; added characters use the system fallback until this script is rerun.
